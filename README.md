# きょうのよていチェッカーVBS｜ver.261123

これは今日の曜日を判定し、その曜日に合った時間割をメッセージボックスで表示するスクリプトです。

このvbsファイルをスタートアップフォルダに入れておけば、起動時（サインイン時）にこのスクリプトが自動起動します。

### 編集方法
answer=MsgBox()内のダブルクオーテーションの中（"今日は◯曜日です"や"１限：〇〇"などの部分）を書き換える。

ちなみに、「,64,」はメッセージボックス内に表示する記号を指定するための数字で、「% vbCrLf &」は改行を意味する。

**注意事項**：文字コードは**ANSI**です。UTF-8だとファイルが文字化けします。また、ファイルを編集する際は、メモ帳の使用をおすすめします。（なぜかVSCodeで開いたら文字化けしました）
