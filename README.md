# きょうのよていチェッカーVBS｜ver.261123

今日の曜日を判定し、その曜日に合った時間割をメッセージボックスで表示するツールです。

これを自分仕様に改造してスタートアップフォルダに入れておくだけで、パソコンを起動するたびにその日の時間割を表示してくれます（全部テキストで）。

要は完全に自己満ですね。

### 編集方法
- today's yotei checker.vbsをダウンロードする。
- ファイルを右クリックしてメニューから`メモ帳で開く`をクリック。
- answer=MsgBox()内のダブルクオーテーションの中（`"今日は◯曜日です"`や`"１限：〇〇"`などの部分）を書き換える。

ちなみに、「,64,」はメッセージボックス内に表示する記号を指定するための数字で、「% vbCrLf &」は改行を意味する。

### 注意事項

VBScriptを動かすための文字コードは**ANSI**（Shift-JIS）です。GitHubからファイルをダウンロードする際、ファイルの文字コードがUTF-8に置き換わっている可能性がありますが、**UTF-8だとスクリプトが動作しません。**  

また、ファイルを編集する際は、メモ帳の使用をおすすめします。（なぜかVSCodeで開いたら文字化けしました）
